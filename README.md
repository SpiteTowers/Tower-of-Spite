# Tower-of-Spite
# This is a game that a small group of people made so it may not be perfect
# The game genres are Tower-Climber, Roguelike, Platformer, fantasy, etc.
# Default Controls
# Keyboard
# Arrow Keys - Movement/Dash Direction
# Shift - Run
# Z - Ability (Dive, Dash, Ledge Dive, Etc.)
# X - Jump
# Alt. Keyboard
# WASD - Movement
# Shift - Run
# P - Ability
# Space - Jump
# Controller (Xbox/Playstation/Nintendo)
# Left Stick - Movement
# LT/L2/ZL - Run
# X/□/Y - Ability
# A/╳/B - Jump

# Artists: Tommy Rodriguez, Daniel Starr
# Coders: Bode Anderson, Tommy Rodriguez, Daniel Starr

# Collision Layers Meaning
# 1-Ground
# 2-Platforms
# 3-Damage
